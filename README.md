# 📐 Sherry's Math - 國二數學互動沙盒

這是一個專為國中二年級（八年級）數學設計的視覺化與互動教具平台。透過幾何拼圖、面積切換與遊戲化關卡，幫助學生以視覺與操作直觀理解抽象的代數與幾何定理。

## ✨ 特色與章節

- **CH1 乘法公式與多項式**
  - **$(a+b)^2$ 幾何視覺化**：自訂邊長 $a$ 與 $b$，即時觀察面積四分割。
  - **拼圖組裝**：動態拼裝驗證公式。
- **CH2 平方根與畢氏定理**
  - **畢氏三元數面積轉移**：直觀展示 $a^2 + b^2 = c^2$ 的方格位移拼貼。
  - **幾何問答與逼近根號**：直角三角形性質與面積數值探索。
- **CH3 因式分解**
  - **十字面積拼圖**：將代數多項式轉化為矩形長寬的因式分解。
  - **因式分解密碼鎖**：結合因數配對與互動解鎖。
- **CH4 一元二次方程式**
  - **神偷開鎖（零乘積定理）**：以齒輪鎖扣視覺化理解雙根由來。
  - **幾何配方拼圖**：動態對稱切分 $6x$ 與手動補磚，直觀理解 $(\frac{b}{2})^2$ 幾何真面目。
  - **拋物線探測員（判別式）**：以水面交點互動探索 $b^2 - 4ac$ 與兩相異根、重根、無解之幾何關係。
